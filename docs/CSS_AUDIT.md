# CSS audit

Audit scope: the renderer stylesheet, appearance controller, native controls, responsive rules, and the CSS entry configured for Tailwind. The renderer uses one global class-based stylesheet plus semantic custom properties; it has no CSS modules or component style sheets. Runtime colors and sizes are supplied through CSS custom properties so saved appearance settings continue to work.

Исключение для значений палитр остаётся в данных настроек, а не в CSS. |

## Правила и проверки

- `stylelint-config-standard` подключён к `npm run lint`; workflow CI уже вызывает этот скрипт.
- Правило `color-no-hex` включено для CSS приложения, файл токенов исключён как единственное место с цветовыми литералами.
- `declaration-no-important` включён без исключений.
- Проверка полноты токенов, контраста текста и значимых границ выполняется для всех шести готовых палитр и пользовательской палитры в светлом и тёмном режимах; крайние акценты включают белый, чёрный, жёлтый и яркие цвета.
- Playwright выполняет 21 сочетание темы/палитры и покрывает значения плотности, масштаба, ширины окна, языка, стороны/свёрнутости панели и типа фона на пяти доступных экранах. Отдельные проверки охватывают смену системной темы, сохранение картинки фона, профиль и снимки светлого/тёмного интерфейса.
- Отдельных экранов таймлайна, логов, извлечения кадров/субтитров и мастера первого запуска в приложении пока нет; обрезка реализована как инструмент на экране конвертера, параметры FFmpeg и сведения о программе — в настройках.
- Размеры и параметры масштаба заданы токенами; viewport breakpoints и ширина содержимого остаются адаптивными.
- Повторные селекторы удалены; активная конфигурация Stylelint запрещает их возвращение.
