# CSS audit

Audit scope: the renderer stylesheet, appearance controller, native controls, responsive rules, and the CSS entry configured for Tailwind. The renderer uses one global class-based stylesheet plus semantic custom properties; it has no CSS modules or component style sheets. Runtime colors and sizes are supplied through CSS custom properties so saved appearance settings continue to work.

| Где | Что было | Что сделано |
| --- | --- | --- |
| `src/renderer/styles.css` | 130 цветовых литералов и три `!important` в глобальных стилях затрудняли поддержку тем и создавали переопределения. | Удалены литералы цветов и `!important`; семантические цвета и прозрачные состояния вынесены в переменные. Исключение для значений палитр остаётся в данных настроек, а не в CSS. |
| `src/renderer/styles/tokens.css` | Не было единого реестра цветов, размеров, шрифтов, радиусов, теней, слоёв и длительностей. | Добавлен источник токенов, в том числе базовая графитовая тема, шкалы и семантические роли для поверхностей, текста, границ, акцента и состояний. Значения темы обновляются в `applyAppearance`. |
| `src/renderer/App.tsx` и native controls | `color-scheme` не синхронизировался с темой; в светлой теме нативные поля могли выглядеть тёмными. Градиенты, тени и border width не учитывали настройки оформления. | `colorScheme` задаётся одновременно с `data-theme`; градиенты и тени пересчитываются для темы, а толщины рамок и длительность анимации управляются токенами. Палитры и предпросмотр передают динамические цвета через CSS-переменные. |
| Стили настроек FFmpeg | Между строками использовались встроенные числовые `marginTop`/`flex` стили. | Статические отступы и ширина заменены классами и токенами. |
| `palette-swatches` | Компонент выставлял класс `selected`, тогда как CSS проверял `active`; выбранная палитра не получала ожидаемого состояния. | Состояние синхронизировано, а каждому swatch добавлена доступная подпись. |
| Свёрнутая боковая панель | Кнопка профиля не показывала имя; меню и навигационные подсказки всегда открывались вправо и могли выходить за правый край окна. Профильная кнопка также не возвращала фокус после закрытия меню с клавиатуры. | Добавлены CSS tooltip из имени профиля, стабильные размеры и центрирование аватара, позиционирование подсказок/меню внутрь окна для обеих сторон, а также закрытие по Escape с возвратом фокуса. |
| `:focus-visible`, скроллбары, `::selection`, disabled и placeholders | Нативные и браузерные состояния были непоследовательны между темами. | Добавлены общие состояния с использованием semantic tokens; чекбоксы и ползунки наследуют системный `color-scheme` и accent color. |
| Глобальный каскад | В исходном файле остались повторные правила и поздние тематические переопределения, мешающие безопасному объединению правил. | Зафиксированы для отдельной консолидации в блоке D; до неё Stylelint проверяет синтаксис, запрет hex и `!important`, но проверки `no-duplicate-selectors` и `no-descending-specificity` временно выключены в конфигурации. |

## Правила и проверки

- `stylelint-config-standard` подключён к `npm run lint`; workflow CI уже вызывает этот скрипт.
- Правило `color-no-hex` включено для CSS приложения, файл токенов исключён как единственное место с цветовыми литералами.
- `declaration-no-important` включён без исключений.
- Размеры интерфейса заданы токенами и масштабируются вместе с `.app-shell`; viewport breakpoints и viewport-relative ширина содержимого оставлены адаптивными.
- Повторные селекторы будут удалены при тематической консолидации в блоке D, после чего соответствующие правила Stylelint будут включены.
