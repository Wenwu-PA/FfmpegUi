# Принятые решения

- Название продукта — **FFmpeg Studio**; в интерфейсе рабочее имя бренда — Frameforge. Иконка приложения — авторский знак киноплёнки и play-треугольника с градиентом; `build/icon.svg` — исходник, `npm run icons` создаёт все платформенные форматы.
- Настройки хранятся в `electron-store`: простой JSON конфиг соответствует небольшому набору настроек первой версии.
- FFmpeg не включается в репозиторий и установщик приложения. Загрузчик запрашивает сеть только по явному действию пользователя; проверенные версии устанавливаются в `userData/ffmpeg/<версия>/` без прав администратора.
- Кодирование запускается в main-процессе через `child_process.spawn` и массив аргументов. Рендерер получает только типизированный мост `contextBridge`.
- Пауза кодирования пока не предлагается, поскольку надёжное приостановление Windows-процесса без дополнительной нативной зависимости не обеспечено. Отмена посылает `q`, затем завершает процесс по таймауту.
- Настройки пока содержат только предпочтения приложения. История задач пока хранится в памяти текущего сеанса; персистентная очередь отложена.
- Интерфейс поддерживает русский и английский языки через небольшой общий каталог `src/shared/i18n.ts`; язык хранится вместе с настройками оформления. Новые строки renderer и Electron должны проходить через `t()`.
- Windows-пакет ограничен x64 и локалями `ru`/`en-US`; в белый список попадают собранные JS/CSS, runtime-пакеты и отдельные иконки/источники FFmpeg. Исполняемый FFmpeg не входит в сборку. NSIS и portable имеют разные имена артефактов, чтобы один таргет не перезаписывал другой.
- Приложение привязывает к окну/задаче и трею отдельные raster assets из `build/`; при упаковке они копируются в `resources/icons`, чтобы runtime не зависел от содержимого исходников.
- Для runtime-иконки окна используется оптимизированный PNG 256×256: этого достаточно для оконных размеров, а Windows `.ico` по-прежнему содержит полный набор размеров до 256×256.
- При совпадении имени результата приложение выбирает имя с числовым суффиксом и запускает FFmpeg в режиме без перезаписи исходного файла.
- Результат сначала записывается во временный файл с исходным расширением и переименовывается атомарно после успешного завершения.

# Стили и темы

- Рендерер использует одну глобальную таблицу классов `src/renderer/styles.css` и единый файл семантических переменных `src/renderer/styles/tokens.css`; графитовая тёмная тема сохранена как значение по умолчанию.
- Тема передаёт `color-scheme` нативным контролам, а параметры внешнего вида обновляют CSS-переменные. Stylelint запускается через `npm run lint`, который уже выполняется в CI.
- Stylelint проверяет дубликаты, запрещает цветовые литералы вне tokens и `!important`; `no-descending-specificity` выключен, так как помечает корректные state-селекторы классового каскада.
- В свёрнутой панели имя доступно как подсказка; меню профиля раскрывается от внешнего края панели к центру окна и закрывается по Escape с возвратом фокуса на кнопку профиля.
- Масштаб 80–150% реализован преобразованием всей оболочки от верхнего левого угла, с базовыми размерами, рассчитанными от viewport. Такое поведение сохраняет доступную ширину боковой панели и не добавляет горизонтальную прокрутку.
- Скриншоты README — сжатые WebP в `docs/screenshots/`; Playwright проверяет предел 300 КБ для создаваемых снимков.
