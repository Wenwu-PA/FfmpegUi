# Заметки по FFmpeg

- В Windows добавьте каталог с `ffmpeg.exe` и `ffprobe.exe` в PATH или укажите путь к `ffmpeg.exe` в настройках.
- Для извлечения кадров нужен видеовход; аудиофайлы не создают миниатюру.
- FFmpeg получает путь входного файла как самостоятельный аргумент. Пробелы и кириллица не проходят через командную оболочку.
- GIF и MP3 используют отдельные аргументы кодирования; видео профили используют H.264/AAC, а компактный профиль — H.265.
